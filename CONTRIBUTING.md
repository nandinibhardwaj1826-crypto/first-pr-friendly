# Contributing

Thanks for helping improve Contribute Together.

## Workflow

1. Fork this repository.
2. Create a branch with a clear name, for example `improve-welcome-copy`.
3. Make one focused improvement.
4. Run `npm install` and `npm run build` locally.
5. Open a pull request explaining what changed and why.

## Good contributions

- Improve copy, documentation, or accessibility labels.
- Refine responsive styles.
- Add a small community-focused feature.
- Fix a bug with a clear reproduction note.

## Pull request checklist

- Keep each pull request focused on one useful change.
- Do not commit generated folders such as `node_modules` or `dist`.
- Be kind and constructive in review discussions.
