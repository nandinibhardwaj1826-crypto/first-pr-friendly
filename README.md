# Contribute Together

A welcoming React project that makes it easy for community members to suggest, build, and share small improvements. Contributors can choose an independent task and open a focused pull request.

## Run locally

```bash
npm install
npm run dev
```

## Ways to contribute

- Add a name to a contributor wall.
- Add a colour palette.
- Improve a sentence or accessibility label.
- Add another beginner-friendly task card.

Keep each pull request focused on one useful change so it is easy to review and build on.
